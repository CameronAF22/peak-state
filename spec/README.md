# Peak State spec

> Generated by `python3 tools/coord.py build` from coord/lanes.json and coord/decisions/. Do not edit by hand.

The spec is the decision log rendered per lane. Each lane file lists the decisions in force, the proposals waiting on someone, and every file the lane owns with the hash it had when the spec was built and the decisions that cover it. A file no decision covers fails CI.

Each branch carries the spec for its own state. The dashboard merges every branch into one live view: https://cameronaf22.github.io/peak-state/

| Lane | Mission | Spec |
|---|---|---|
| `coord` Coordination and spec | Run the protocol: lanes, the decision log, the generated spec, the dashboard, hooks and CI. Integrate lane branches into main and keep the board honest. | [coord.md](coord.md) |
| `contracts` Data contracts and API | Own every shape the lanes exchange: the three-emotion profile, calibration, signal frames, detection events, rep sessions, and the app-to-module API. Ship schemas, fixtures, generated types and contract tests first so every other lane can build against fixtures in parallel. | [contracts.md](contracts.md) |
| `onboarding` Onboarding and strategy elicitation | Turn a first conversation into a confirmed profile: find the person's three top emotions and, for each, the strategy they already use to get there. Capture a short calibration of what each state looks like in their signals. | [onboarding.md](onboarding.md) |
| `sensing` Sensing and detection | Get signals in and decide when to fire a rep: a deterministic simulator for the demo, a Web Bluetooth heart-rate strap as the real sensor, a manual trigger, and a personal-baseline detector with a gate. | [sensing.md](sensing.md) |
| `reps` Repetition and conditioning engine | Install each state as measurable reps: a short rep script per emotion (anchor, physiology, focus, language, rate), anchor conditioning, rep counting, an installed test, and recovery measured against sham. | [reps.md](reps.md) |
| `experience` App experience and demo | Own what a judge touches: the web app that runs onboarding, calibration, live detection, the rep and progress, wired to the other lanes' modules, plus the three-minute demo script. | [experience.md](experience.md) |
